## About this Specialization

The Machine Learning Specialization is a beginner-friendly online program developed through a collaboration between DeepLearning.AI and Stanford Online. It introduces learners to the core concepts of machine learning and demonstrates how these techniques can be applied to create practical AI solutions.

The specialization is taught by Andrew Ng, a leading figure in artificial intelligence who has contributed to major advancements in the field through his work at Stanford University, Google Brain, Baidu, and Landing AI.

This three-course program is an updated edition of Andrew Ng’s highly acclaimed Machine Learning course, which has helped millions of learners worldwide since its original launch in 2012.

The curriculum covers a wide range of modern machine learning topics, including supervised learning techniques such as linear regression, logistic regression, neural networks, and decision trees, as well as unsupervised learning methods like clustering, dimensionality reduction, and recommender systems. It also introduces industry best practices for building and improving AI models, including model evaluation, tuning, and data-centric development approaches.

By completing this specialization, learners gain both theoretical understanding and practical experience needed to apply machine learning effectively to real-world challenges. It serves as an excellent starting point for anyone interested in pursuing a career in AI or machine learning.

## 📚 Contents

### 0. Basics and Others
Foundational tools and concepts used throughout the specialization:
- Python essentials for ML
- NumPy, Matplotlib, and data manipulation
- Jupyter Notebook workflows

---

### 1. Supervised Machine Learning – Regression and Classification
Core supervised learning concepts:
- **Linear Regression** – Univariate and multivariate
- **Gradient Descent** – Cost function minimization
- **Feature Engineering & Scaling**
- **Logistic Regression** – Binary classification
- **Overfitting & Regularization** – L1/L2 regularization techniques

---

### 2. Advanced Learning Algorithms
Neural networks and tree-based methods:
- **Neural Networks** – Forward and backward propagation
- **TensorFlow / Keras** – Building and training models
- **Activation Functions** – ReLU, Sigmoid, Softmax
- **Model Evaluation** – Bias/Variance tradeoff, learning curves
- **Decision Trees & Random Forests**
- **Boosting** – XGBoost and ensemble methods

---

### 3. Unsupervised Learning, Recommenders, Reinforcement Learning
Beyond labeled data:
- **K-Means Clustering**
- **Anomaly Detection**
- **Collaborative Filtering** – Recommender systems
- **Content-Based Filtering**
- **Principal Component Analysis (PCA)**
- **Reinforcement Learning** – Q-learning, policy optimization

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ashfak-Uzzaman/Machine-Learning-Study.git
   cd Machine-Learning-Study
   ```

2. **Install dependencies**
   ```bash
   pip install numpy matplotlib scikit-learn tensorflow jupyter
   ```

3. **Launch Jupyter Notebook**
   ```bash
   jupyter notebook
   ```

4. Navigate to any course folder and open the `.ipynb` files to explore notes and labs.
